# MORROW STUDIO
### Discover Your Everyday Essentials

MORROW STUDIO is a modern lifestyle shopping website designed to provide a smooth, visually engaging and user-friendly online shopping experience.

The website brings together carefully presented products, organised categories and convenient shopping features in one responsive platform.

## About the Project

This project was developed using HTML, CSS and JavaScript. It focuses on modern web design principles, responsive layouts, accessibility, search engine optimisation and interactive front-end functionality.

## Features

- Modern and responsive user interface
- Home, About and Contact pages
- Separate Login and Sign Up pages
- Product categories and product collections
- Individual product detail pages
- Product search and sorting
- Pagination for product browsing
- Interactive shopping cart with a sliding side panel
- Cart quantity management and item removal
- Light and Dark theme options
- Location page featuring Karachi
- Form validation
- Responsive navigation
- Search Engine Optimisation (SEO)
- Accessible interface improvements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Google Fonts
- Bootstrap Icons (where included)
- GitHub Pages

## Website Structure

The project contains separate pages for different sections of the website, including:

- `index.html` – Home page
- `about.html` – About page
- `contact.html` – Contact page
- `login.html` – Login page
- `signup.html` – Sign Up page
- `product-details.html` – Product details
- Location page – Location information

Additional CSS, JavaScript and image assets are organised in their respective project folders.

## Getting Started

To view the website locally:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install or enable the Live Server extension.
4. Open `index.html` using Live Server.
5. Browse the website.

## Deployment

This website can be hosted using GitHub Pages.

To publish:

1. Open the repository Settings.
2. Navigate to Pages.
3. Select Deploy from a branch.
4. Select the `main` branch.
5. Select the root folder.
6. Save the settings.

Once deployment is complete, GitHub Pages will provide a public website link.
